1. 概述

1.1 什么是 Chrome MCP Bridge？

它是一个 MCP (Model Context Protocol) 服务器，把真实 Chrome/Chromium 浏览器的能力暴露给 AI 助手。与 Playwright 等方案不同：

对比维度 Playwright MCP Chrome MCP Bridge (本方案)
浏览器 启动独立无头浏览器 使用你日常的 Chromium
登录态 ❌ 需重新登录 ✅ 保留所有已登录网站
资源占用 额外浏览器进程 复用已有浏览器
安装依赖 Playwright + 浏览器二进制 仅需 Python + websocket-client
启动速度 慢（需启动浏览器） 快（Bridge 常驻）

1.2 核心能力

  • ✅ 浏览任意网页：导航到指定 URL（包括需要登录的网站）
  • ✅ 提取完整正文：获取页面标题、描述、正文文本，自动去除导航栏/广告/页脚
  • ✅ 保留登录态：小红书、知乎、B站等已登录网站直接可用
  • ✅ 短链追踪：自动跟随 xhslink.com 等短链接重定向

1.3 适用场景

  • 让 AI 帮你阅读小红书笔记、知乎文章等需要登录的内容
  • 让 AI 实时查询网页信息（新闻、文档、价格等）
  • 结合其他 MCP 工具，实现「浏览 → 提取 → 分析 → 操作」的自动化流水线

2. 架构说明

┌──────────────┐     HTTP (MCP JSON-RPC)     ┌──────────────┐     WebSocket (CDP)     ┌──────────────┐
│              │ ──────────────────────────▶ │              │ ─────────────────────▶ │              │
│  MCP 客户端   │    :9224                    │  MCP Bridge  │    :9223               │  Chromium    │
│  (RikkaHub等) │ ◀────────────────────────── │  (Python)    │ ◀───────────────────── │  (你的浏览器)  │
│              │                             │              │                         │              │
└──────────────┘                             └──────────────┘                         └──────────────┘
  • 9223 端口：Chromium DevTools Protocol（CDP）调试端口，Bridge 通过 WebSocket 连接
  • 9224 端口：MCP Bridge HTTP 端口，AI 客户端连接此处
  • Bridge：Python 脚本，负责翻译 MCP 协议 ↔︎ CDP 协议

Bridge 监听 0.0.0.0:9224，局域网可直接访问。远程访问需搭配 Tailscale 组网（自带端到端加密）。

#!/bin/bash

  --remote-debugging-port=9223 \
  --remote-allow-origins=* \
  --no-first-run \
  --no-default-browser-check \
  --disable-component-update \
  --restore-last-session \

关键参数说明：

--no-first-run 跳过首次运行向导
--restore-last-session 恢复上次的标签页（保留登录态）

5. Step 2：编写 MCP Bridge

5.1 创建 Bridge 脚本

将完整脚本保存到 /opt/chrome_mcp_bridge.py（完整源码见 附录）。

sudo cp chrome_mcp_bridge.py /opt/chrome_mcp_bridge.py
sudo chmod +x /opt/chrome_mcp_bridge.py

5.2 核心逻辑说明

Bridge 的核心是 CDPClient 类，它通过 WebSocket 向 Chromium 发送 CDP 命令：

class CDPClient:
    def evaluate(self, expression: str) -> dict:
        """在页面中执行 JavaScript 并返回结果"""
        return self.send("Runtime.evaluate", {
            "expression": expression,
            "returnByValue": True,
        })

提取页面内容的原理是注入 JavaScript 来获取 DOM 文本：

// 核心提取逻辑
var article = document.querySelector('article');
var main = document.querySelector('main');
var el = article || main || document.body;
var clone = el.cloneNode(true);
// 移除无关元素
clone.querySelectorAll('script, style, nav, footer, header, .ad').forEach(n => n.remove());
return clone.innerText;

5.3 注意事项

  • 网页提取上限：默认截取前 50000 字符，避免 token 爆炸
  • 短链重定向：chrome_navigate 自动跟随 HTTP 重定向
  • SPA 页面：小红书、知乎等单页应用需要等待 JS 渲染（Bridge 内置 1 秒等待）

7. Step 4：注册为系统服务

7.1 创建 systemd 服务文件

/etc/systemd/system/chrome-mcp-bridge.service：

[Unit]
Description=Chrome MCP Bridge (CDP-based)
After=network.target

[Service]
Type=simple
User=你的用户名
ExecStart=/usr/bin/python3 /opt/chrome_mcp_bridge.py
Restart=always
RestartSec=5
StandardOutput=append:/var/log/chrome_mcp_bridge.log
StandardError=append:/var/log/chrome_mcp_bridge.log

[Install]
WantedBy=multi-user.target

7.2 启用服务

sudo cp chrome-mcp-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable chrome-mcp-bridge

9. Step 6：Tailscale 远程访问（可选）

如果你只在局域网内使用 Chrome MCP，可以跳过本章。
如果你想让 AI 在任何地方（出门用流量、在公司、出差）都能操控家里的浏览器，请继续。

9.1 为什么需要 Tailscale？

Bridge 监听的是局域网 IP（如 192.168.x.x），离开 WiFi 范围就无法访问。直接暴露到公网非常危险（无 HTTPS、无认证）。

Tailscale 是基于 WireGuard 的零配置 VPN： - 设备之间组成虚拟私有网络，分配 100.x.x.x 地址 - 自带端到端加密，无需暴露端口到公网 - 在家自动走局域网直连（低延迟），出门走中继转发

9.2 安装 Tailscale

在 Ubuntu 笔记本上：

# 安装
curl -fsSL https://tailscale.com/install.sh | sh

# 启动并认证（会输出一个 URL，在浏览器中打开确认）
sudo tailscale up

# 验证
tailscale ip -4
# 输出类似：100.71.245.14

在其他设备上（Windows/macOS/Android/iOS）：

从 tailscale.com/download 下载客户端，用同一账号登录。

所有设备加入同一个 tailnet 后，互相可以通过 100.x.x.x 地址访问。

9.3 获取 Auth Key（防掉线）

Tailscale 的网页登录是一次性的——系统重启或 tailscaled 服务重启后可能掉线。Auth Key 可以持久化认证。

  1. 打开 Tailscale Admin Console
  2. 点击 Generate auth key
  3. 设置：
    • Description：my-laptop（随意填写）
    • Reusable：✅ 勾选（重要！）
    • Ephemeral：❌ 不勾
    • Expiration：90 天（最大）
  4. 点击生成，复制 tskey-auth-... 开头的密钥

注意：密钥 90 天到期后需重新生成一个。但已认证的设备不会掉线——密钥只是”准入凭证”，认证完就绑定设备密钥了。只有设备被手动从 tailnet 移除后才需要新密钥。

9.4 使用 Auth Key 绑定

# 用 Auth Key 认证（替代浏览器登录）
sudo tailscale up --authkey=tskey-auth-你的密钥 --accept-routes

# 验证是否在线
tailscale status
# 应显示你的设备，不带 "offline" 标记

11. 故障排查

Q1：Bridge 启动后 9224 端口无监听

# 前台运行看日志
python3 /opt/chrome_mcp_bridge.py

常见原因： - Chromium 未以调试模式启动（检查 9223 端口） - Python 缺少 websocket-client 包

Q2：Chromium 调试端口连不上 / 403 Forbidden

症状：

Rejected an incoming WebSocket connection from the http://127.0.0.1:9223 origin.

解决：启动 Chromium 时必须加 --remote-allow-origins=*

Q3：提取的内容只有页脚没有正文（小红书等 SPA）

小红书等单页应用内容由 JS 动态渲染。

解决：在 chrome_navigate 之后等待 2-3 秒再调 chrome_get_web_content。Bridge 已内置 1 秒等待，复杂页面可适当增加。

Q4：Snap 版 Chromium 的问题

Ubuntu 24.04 默认通过 Snap 安装 Chromium。Snap 沙箱可能限制某些功能。

检查是否 Snap 版本：

which chromium-browser
# 如果输出 /snap/chromium/... 则为 Snap 版

本方案采用 CDP 方式通信，已验证在 Snap 版 Chromium 上正常工作。如果遇到其他问题，可安装 apt 版本：

sudo snap remove chromium
sudo apt install chromium-browser

Q5：DISPLAY / X 认证错误

# 找到 X 认证文件
ls /run/user/1000/.mutter-Xwaylandauth.*
# 设置环境变量
export DISPLAY=:0
export XAUTHORITY=/run/user/1000/.mutter-Xwaylandauth.XXXXXX

Q6：Bridge 意外退出

Bridge 作为 systemd 服务运行时会自动重启（Restart=always）。 查看退出原因：

sudo journalctl -u chrome-mcp-bridge -n 50

12. 安全注意事项

11.1 端口暴露

  • 9223 端口 仅监听 127.0.0.1，外部无法访问 ✅
  • 9224 端口 监听 0.0.0.0（所有接口），局域网其他设备可访问 ⚠️

如需限制 9224 仅本地访问，修改 Bridge 源码中的 BRIDGE_HOST = "127.0.0.1"。

如果 MCP 客户端在远程（如云端 RikkaHub），需要通过 Tailscale 等 VPN 组网，不要直接把 9224 暴露到公网。

11.2 浏览器登录态

因为使用的是你日常的 Chromium，所有已登录的网站（小红书、B站、GitHub 等）都对 AI 可见。请确保： - 只给可信的 MCP 客户端配置此 Bridge - 不要在共享设备上运行此设置 - 敏感账户（银行、支付等）建议使用单独的浏览器配置文件

11.3 HTTPS

Bridge 本身不支持 HTTPS。如需加密传输，可通过 Nginx 反向代理或使用 Tailscale（自带端到端加密）。

11.4 身份认证

当前版本 Bridge 没有内置认证。如需添加 Bearer Token 认证，可在 do_POST 方法中添加校验逻辑。参考实现：

AUTH_TOKEN = "your-secret-token"

def do_POST(self):
    auth = self.headers.get("Authorization", "")
    if auth != f"Bearer {AUTH_TOKEN}":
        self._send_json({"error": "Unauthorized"}, 401)
        return
    # ... 原有逻辑

13. 附录：完整 Bridge 源码

保存为 /opt/chrome_mcp_bridge.py

#!/usr/bin/env python3
"""
Chrome MCP Bridge - CDP-based MCP server for Chromium browser control.

Architecture:
  MCP Client -> HTTP :9224 (this bridge) -> CDP WebSocket :9223 -> Chromium

Provides:
  - chrome_navigate: Open a URL and return page title
  - chrome_get_web_content: Extract full text content from current page
"""

import http.server
import json
import urllib.request
import urllib.error
import threading
import time
import logging
import sys
import os

try:
    import websocket
except ImportError:
    print("Error: websocket-client not installed.")
    print("Run: pip3 install --break-system-packages websocket-client")
    sys.exit(1)

# ---------------------------------------------------------------------------
# Configuration
# ---------------------------------------------------------------------------
CDP_HOST = "127.0.0.1"
CDP_PORT = 9223
BRIDGE_HOST = "0.0.0.0"   # 改为 "127.0.0.1" 可限制仅本地访问
BRIDGE_PORT = 9224

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    handlers=[logging.StreamHandler(sys.stderr)],
)
logger = logging.getLogger("chrome-mcp-bridge")


# ---------------------------------------------------------------------------
# CDP Client
# ---------------------------------------------------------------------------
class CDPClient:
    """Minimal CDP WebSocket client for Chrome DevTools Protocol."""

    def __init__(self, ws_url: str):
        self.ws_url = ws_url
        self.ws: websocket.WebSocket | None = None
        self._msg_id = 0
        self._lock = threading.Lock()

    def connect(self) -> None:
        self.ws = websocket.create_connection(self.ws_url, timeout=10)
        logger.info("CDP connected to %s", self.ws_url)

    def close(self) -> None:
        if self.ws:
            self.ws.close()
            self.ws = None

    def send(self, method: str, params: dict | None = None) -> dict:
        """Send a CDP command and return the result dict."""
        if not self.ws:
            raise RuntimeError("CDP not connected")
        with self._lock:
            self._msg_id += 1
            msg_id = self._msg_id
            payload = {"id": msg_id, "method": method, "params": params or {}}
            self.ws.send(json.dumps(payload))
            while True:
                resp = json.loads(self.ws.recv())
                if resp.get("id") == msg_id:
                    if "error" in resp:
                        raise RuntimeError(f"CDP error: {resp['error']}")
                    return resp.get("result", {})
                # Ignore events / other messages

    def evaluate(self, expression: str, await_promise: bool = False) -> dict:
        """Run JavaScript in the page context."""
        return self.send("Runtime.evaluate", {
            "expression": expression,
            "returnByValue": True,
            "awaitPromise": await_promise,
        })

# Helpers
# ---------------------------------------------------------------------------
def get_active_tab() -> dict | None:
    """Return the first 'page' target from CDP /json endpoint."""
    try:
        resp = urllib.request.urlopen(
            f"http://{CDP_HOST}:{CDP_PORT}/json", timeout=5
        )
        targets = json.loads(resp.read())
        for t in targets:
            if t.get("type") == "page":
                return t
    except Exception as e:
        logger.error("Failed to fetch CDP target list: %s", e)
    return None


def get_page_content(cdp: CDPClient) -> str:
    """Extract readable text content from current page."""
    script = r"""
    (function() {
        var article = document.querySelector('article');
        var main = document.querySelector('main');
        var body = document.body;
        var el = article || main || body;
        if (!el) return '';
        var clone = el.cloneNode(true);
        var removes = clone.querySelectorAll(
            'script, style, noscript, svg, nav, footer, header, iframe, ' +
            '[hidden], [aria-hidden="true"], .sidebar, .ad, .advertisement'
        );
        removes.forEach(function(n) { n.remove(); });
        var text = clone.innerText || clone.textContent || '';
        text = text.replace(/[ \t]+/g, ' ').replace(/\n{3,}/g, '\n\n').trim();
        if (text.length > 50000) text = text.substring(0, 50000) + '\n\n... [TRUNCATED]';
        return text;
    })()
    """
    result = cdp.evaluate(script)
    return result.get("result", {}).get("value", "")


def get_page_metadata(cdp: CDPClient) -> dict:
    """Extract page metadata."""
    script = r"""
    (function() {
        var meta = {};
        meta.title = document.title || '';
        var desc = document.querySelector('meta[name="description"]');
        meta.description = desc ? desc.getAttribute('content') : '';
        var author = document.querySelector('meta[name="author"]');
        meta.author = author ? author.getAttribute('content') : '';
        meta.language = document.documentElement.lang || '';
        return meta;
    })()
    """
    result = cdp.evaluate(script)
    value = result.get("result", {}).get("value", {})
    if isinstance(value, str):
        try:
            value = json.loads(value)
        except json.JSONDecodeError:
            value = {"title": value}
    return value

# MCP HTTP Handler
# ---------------------------------------------------------------------------
class MCPHandler(http.server.BaseHTTPRequestHandler):
    """Handles MCP JSON-RPC over HTTP."""

    protocol_version = "HTTP/1.0"

    def _send_json(self, data: dict, status: int = 200) -> None:
        body = json.dumps(data, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Connection", "close")
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self) -> None:
        self._send_json({"error": "use POST"}, 405)

    def do_POST(self) -> None:
        try:
            body_len = int(self.headers.get("Content-Length", 0))
            body = json.loads(self.rfile.read(body_len)) if body_len else {}
        except (json.JSONDecodeError, ValueError) as e:
            self._send_json(
                {"jsonrpc": "2.0", "error": {"code": -32700, "message": str(e)}}, 400
            )
            return

        method = body.get("method", "")
        req_id = body.get("id", 0)

        # --- MCP protocol handshake ---
        if method == "initialize":
            self._send_json({
                "jsonrpc": "2.0",
                "id": req_id,
                "result": {
                    "protocolVersion": "2025-06-18",
                    "capabilities": {"tools": {}},
                    "serverInfo": {"name": "ChromeMCP-CDP", "version": "2.0"},
                },
            })
            return

        if method == "notifications/initialized":
            self._send_json({"jsonrpc": "2.0", "id": req_id, "result": {}})
            return

        # --- tools/list ---
        if method == "tools/list":
            self._send_json({
                "jsonrpc": "2.0",
                "id": req_id,
                "result": {
                    "tools": [
                        {
                            "name": "chrome_navigate",
                            "description": "打开指定URL的网页，并返回页面标题和URL",
                            "inputSchema": {
                                "type": "object",
                                "properties": {
                                    "url": {
                                        "type": "string",
                                        "description": "要打开的网页URL",
                                    },
                                },
                                "required": ["url"],
                            },
                        },
                        {
                            "name": "chrome_get_web_content",
                            "description": "获取当前活跃网页的完整文本内容，包括标题、正文、元数据",
                            "inputSchema": {
                                "type": "object",
                                "properties": {
                                    "url": {
                                        "type": "string",
                                        "description": "可选：先导航到此URL再获取内容",
                                    },
                                },
                            },
                        },
                    ],
                },
            })
            return

        # --- tools/call ---
        if method == "tools/call":
            params = body.get("params", {})
            tool_name = params.get("name", "")
            args = params.get("arguments", {})
            tool_result = self._execute_tool(tool_name, args)
            self._send_json({
                "jsonrpc": "2.0",
                "id": req_id,
                "result": {"content": [{"type": "text", "text": tool_result}]},
            })
            return

        # --- unknown ---
        self._send_json({
            "jsonrpc": "2.0",
            "id": req_id,
            "error": {"code": -32601, "message": f"unknown method: {method}"},
        })

    def _execute_tool(self, name: str, args: dict) -> str:
        if name == "chrome_navigate":
            return self._chrome_navigate(args.get("url", ""))
        if name == "chrome_get_web_content":
            target_url = args.get("url", "")
            if target_url:
                nav_result = self._chrome_navigate(target_url)
                if "错误" in nav_result:
                    return f"Navigation failed: {nav_result}"
            return self._chrome_get_web_content()
        return f"Unknown tool: {name}"

    def _chrome_navigate(self, url: str) -> str:
        """Navigate to a URL using CDP."""
        if not url:
            return "错误: 未提供URL"

        # Method 1: Create new tab
        try:
            req = urllib.request.Request(
                f"http://{CDP_HOST}:{CDP_PORT}/json/new?"
                f"{urllib.parse.quote(url, safe='')}",
                method="PUT",
            )
            with urllib.request.urlopen(req, timeout=10) as r:
                tab_info = json.loads(r.read())
                ws_url = tab_info.get("webSocketDebuggerUrl", "")
                cdp = CDPClient(ws_url)
                cdp.connect()
                try:
                    cdp.send("Page.enable")
                    time.sleep(1)
                    result = cdp.evaluate("document.title")
                    title = result.get("result", {}).get("value", "")
                finally:
                    cdp.close()
                return f"已打开 {url}\n标题: {title}"
        except Exception as e:
            logger.error("Navigate method 1 error: %s", e)

        # Method 2: Navigate existing tab
        tab = get_active_tab()
        if tab and tab.get("webSocketDebuggerUrl"):
            try:
                cdp = CDPClient(tab["webSocketDebuggerUrl"])
                cdp.connect()
                try:
                    cdp.send("Page.enable")
                    cdp.send("Page.navigate", {"url": url})
                    time.sleep(1)
                    title = (
                        cdp.evaluate("document.title")
                        .get("result", {})
                        .get("value", "")
                    )
                finally:
                    cdp.close()
                return f"已导航到 {url}\n标题: {title}"
            except Exception as e2:
                logger.error("Navigate method 2 error: %s", e2)

        return (
            f"错误: 无法打开 {url}，"
            "请确认 Chromium 正在运行并开启了调试端口 9223"
        )

    def _chrome_get_web_content(self) -> str:
        """Get full page content using CDP."""
        tab = get_active_tab()
        if not tab:
            return "错误: 没有活跃的网页标签页"

        ws_url = tab.get("webSocketDebuggerUrl", "")
        if not ws_url:
            return "错误: 无法获取页面调试 URL"

        try:
            cdp = CDPClient(ws_url)
            cdp.connect()
            try:
                cdp.send("Page.enable")
                cdp.send("Runtime.enable")

                meta = get_page_metadata(cdp)
                title = meta.get("title", tab.get("title", ""))
                url = tab.get("url", "")
                text_content = get_page_content(cdp)

                lines = []
                lines.append(f"URL: {url}")
                lines.append(f"标题: {title}")
                if meta.get("description"):
                    lines.append(f"描述: {meta['description']}")
                if meta.get("author"):
                    lines.append(f"作者: {meta['author']}")
                if meta.get("language"):
                    lines.append(f"语言: {meta['language']}")
                lines.append("")
                lines.append("--- 页面正文 ---")
                lines.append(
                    text_content if text_content else "(无法提取页面内容)"
                )
                return "\n".join(lines)
            finally:
                cdp.close()
        except Exception as e:
            logger.error("get_web_content error: %s", e)
            return f"错误: 获取页面内容失败 - {e}"


# ---------------------------------------------------------------------------
# Main
# ---------------------------------------------------------------------------
def main():
    logger.info("Checking CDP endpoint %s:%d ...", CDP_HOST, CDP_PORT)
    for attempt in range(5):
        tab = get_active_tab()
        if tab:
            logger.info("CDP OK – found tab: %s", tab.get("title", "?"))
            break
        logger.info("Waiting for CDP... attempt %d/5", attempt + 1)
        time.sleep(2)
    else:
        logger.warning(
            "No CDP tab found. "
            "Make sure Chromium is running with --remote-debugging-port=%d",
            CDP_PORT,
        )

    import socketserver

    class ReusableTCPServer(socketserver.TCPServer):
        allow_reuse_address = True

    server = ReusableTCPServer((BRIDGE_HOST, BRIDGE_PORT), MCPHandler)
    logger.info(
        "Chrome MCP Bridge listening on %s:%d", BRIDGE_HOST, BRIDGE_PORT
    )
    logger.info("CDP target: %s:%d", CDP_HOST, CDP_PORT)
    logger.info("Available tools: chrome_navigate, chrome_get_web_content")

    try:
        server.serve_forever()
    except KeyboardInterrupt:
        logger.info("Shutting down.")
        server.shutdown()


if __name__ == "__main__":
    main()
